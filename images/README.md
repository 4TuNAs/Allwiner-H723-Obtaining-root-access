# Tested board photos

The photographed and tested PCB is **H723-6621-V1.2**.

- `h723-6621-v1.2-uart-location.jpg` — the UART connector area is marked.
- `h723-6621-v1.2-usb-adb-wiring.jpg` — the soldered USB data connection used for recovery ADB is marked; the photographed +5 V/GND power pins are also labeled.

The current UART photo identifies the connector location, but it does **not** document the exact per-pin GND/TX/RX order. Do not guess the pin order from wire colors. Confirm it on your own board before connecting a USB-UART adapter.
